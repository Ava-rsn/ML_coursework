# ML Coursework

Core machine learning models and evaluation methods, implemented in Python.

## Covers
- SVMs and logistic regression (digit classification)
- K-Means and GMMs (clustering)
- HMMs (time-series modelling)
- PCA, Bayesian inference, k-fold cross-validation

## Evaluation
Compared models using accuracy, F1, NMI, ARI, silhouette score, and log-likelihood.
